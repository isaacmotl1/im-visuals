# Image placeholders

This project uses remote placeholder photography so the first preview has a refined editorial feel without committing large image files to the repository.

When replacing images, add the photographs in these folders and update the `src` field in `script.js`:

- `landscape/` — 8 images: `landscape-01.jpg` through `landscape-08.jpg`
- `sports/` — 12 images: `sport-01.jpg` through `sport-12.jpg`
- `wildlife/` — 8 images: `wildlife-01.jpg` through `wildlife-08.jpg`
- `portraits/` — 8 images: `portrait-01.jpg` through `portrait-08.jpg`
- `aviation/` — 8 images: `aviation-01.jpg` through `aviation-08.jpg`

Use photos cropped to a 3:4 portrait ratio for the portfolio grid. The site currently declares exactly 44 replaceable image slots—the requested counts above.
